## 设计语言

### 核心理念

> 远程桌面就是产品。UI 是透明的桥梁——按需出现，自动消失。

所有 UI 元素采用 **深色半透明悬浮层**，覆盖在远程桌面画面之上。理由：
1. 远程桌面配色不可控——深色 Chrome 不会与任何桌面主题冲突
2. 视觉后退——用户焦点在桌面内容，不在控制元素
3. 行业惯例——Citrix、VMware、Parsec 均采用深色悬浮 Chrome

### 1.4 连接健康脉冲点

这是始终可见的 UI 唯一常驻元素：


## 五、动效规范

| 元素 | 触发 | 动画 | 时长 | 缓动 |
|------|------|------|------|------|
| 工具栏 | 鼠标触顶 | translateY(-100%) → 0 | 250ms | ease-out |
| 工具栏 | 自动隐藏 | translateY(0) → -100% | 200ms | ease-in |
| 文件面板 | 点击📁 | translateX(100%) → 0 | 300ms | ease-out |
| 连接进度 | 进入连接 | opacity 0 → 1 | 300ms | ease-out |
| 重连通知 | 断线检测 | translateY(100%) → 0 | 200ms | ease-out |
| 引导弹窗 | 打开引导 | opacity 0 + scale(0.95) → 1 | 300ms | ease-out |
| 按钮高亮 | 引导脉冲 | box-shadow 扩散 | 1500ms | 循环 |
| 健康脉冲 | 正常连接 | scale + opacity 波动 | 2000ms | 循环 |

**reduced-motion 适配**：
- 所有动画替换为即时切换（0ms）
- 脉冲点变为静态色块
- 工具栏直接显示/隐藏无滑入

## 六、无障碍

| 要求 | 实现 |
|------|------|
| 键盘导航 | Tab 遍历工具栏按钮，Enter/Space 激活 |
| 焦点可见 | 聚焦按钮显示 2px --accent 轮廓 |
| ARIA 标签 | 工具栏 `role="toolbar"`，按钮 `aria-label` |
| 屏幕阅读器 | 连接状态变化通过 `aria-live="polite"` 通告 |
| 颜色对比 | 所有文字在深色背景上对比度 ≥4.5:1 |
| 减弱动画 | `prefers-reduced-motion` 关闭所有非必要动画 |
